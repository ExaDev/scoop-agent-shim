# scoop-agent-shim

[Scoop](https://scoop.sh) bucket for [agent-shim](https://github.com/ExaDev/agent-shim) on Windows.

## Install

```powershell
scoop bucket add agent-shim https://github.com/ExaDev/scoop-agent-shim
scoop install agent-shim
```

This installs `agent-shim` alone, the same as the project's own binary installer and `npm install -g agent-shim`, and also puts the `claude-use` command (the project's former name) on your PATH. It does not install a `claude` command; run `agent-shim shim enable` afterward if you'd also like the shorter `claude @<name>` form (`agent-shim shim disable` undoes it). See [the main repo's Install section](https://github.com/ExaDev/agent-shim#install) for the full comparison across all distribution channels.

## Renamed from claude-use

The project was called claude-use, and this bucket was `scoop-claude-use`. Scoop has no way to rename a package, so `bucket/claude-use.json` stays and tracks every release as a copy of `bucket/agent-shim.json`: an existing `scoop install claude-use` keeps updating, and installs the same files. New installs should use `agent-shim`. Installing both at once is not useful; they ship the same program.

If you added the bucket under its old name, `scoop bucket rm claude-use` and `scoop bucket add agent-shim https://github.com/ExaDev/scoop-agent-shim` moves you to the new one (GitHub redirects the old URL, so the old bucket entry keeps working too).

## Manifests

`bucket/agent-shim.json` and `bucket/claude-use.json` are auto-generated by agent-shim's own CI release pipeline on every tagged release. Manual edits will be overwritten.
